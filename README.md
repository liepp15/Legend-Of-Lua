# Legend of Lua (versi game saja)
Jalankan lewat server lokal (game memuat peta via fetch, jadi tidak bisa dibuka langsung dengan file://):
`python3 -m http.server` lalu buka http://localhost:8000/ (atau pakai Live Server / GitHub Pages / Vercel).
Tanpa login: progres, emas, dan skor tersimpan otomatis di Local Storage browser (profil "player").
Kontrol: WASD gerak, Spasi roll, klik serang, Shift+klik api, Tab ganti item, Backspace layar penuh.
